# MANUAL_TESTING · 公众号编辑器粘贴实测

> 对应 [PRD.md §10.4](./PRD.md) 发版实测清单。自动化测试（73 用例）保证文件级正确性；「粘贴进公众号编辑器后所见一致」必须人工实测，本文是标准步骤与核对表。

## 0. 前置

- 测试文章：`test/fixtures/paste-test.md`（覆盖全部排版元素、两张表格、题注、本地 + 外部图片）；
- 注册并引用 songmo 模板：

```bash
md2mp template add songmo ./templates/songmo
```

- 公众号后台任意可登录账号；浏览器以 Chrome 为主测。

## 1. 生成三种图片模式的产物

```bash
# data 模式（离线可用，无需凭据）
md2mp build test/fixtures/paste-test.md -t songmo -p 庄重 --image-mode data -o /tmp/mp-accept-data

# link 模式（外链保留）
md2mp build test/fixtures/paste-test.md --image-mode link -o /tmp/mp-accept-link

# upload 模式（需凭据 + IP 白名单）
export MP_APPID=... MP_SECRET=...
md2mp build test/fixtures/paste-test.md --image-mode upload -o /tmp/mp-accept-upload
```

## 2. 核对步骤

1. 打开 `preview.html`，侧栏应为「无问题」或仅 MP010/MP020 警告（外链图片/外链文章）；
2. 点「一键复制」；
3. 到 mp.weixin.qq.com 图文编辑器正文，Ctrl+V / Cmd+V 粘贴；
4. 按下表逐项核对，结果记入 §4 记录表。

### 3.1 图片模式矩阵

| 模式 | 本地图片预期 | 外部图片预期 | 结果 |
| --- | --- | --- | --- |
| data | 内嵌显示（data URL） | 保留原链接，可能显示/不显示（记录） | ☐ |
| link | 警告「公众号无法访问」且不显示 | 保留 https 链接，可能显示/不显示（记录） | ☐ |
| upload | 上传为 mmbiz.qpic.cn 链接并显示 | 保留原链接 + MP010 警告 | ☐ |

### 3.2 重点验证项

- **data URL 粘贴转存（PRD Q1）**：data 模式下粘贴后，本地图片是否被编辑器自动转存为微信图床（右键图片查看地址），结论记录于 [HISTORY.md](./HISTORY.md)；
- **粘贴后再次复制**：从编辑器剪切到另一篇图文，样式是否保持；
- **手机预览**：编辑器「预览」发到手机，字号/行距/表格是否正常。

## 6. publish 干跑（有认证号时）

```bash
md2mp publish test/fixtures/paste-test.md --dry-run   # 只传图 + 输出草稿 JSON
md2mp publish test/fixtures/paste-test.md             # 写入草稿箱
```

核对：dry-run JSON 的图片均为 mmbiz 链接；正式执行后草稿箱出现文章，封面正确、标题/摘要/作者正确、正文与预览一致。
